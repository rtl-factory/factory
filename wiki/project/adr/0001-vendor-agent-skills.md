# Adopt upstream agent skills as BKMs, not as installed skills

We take the method from third-party agent skills (starting with mattpocock/skills, MIT) and copy it into the repo as BKMs, rather than installing the skills as a self-updating plugin or keeping them as chained skills. Committed copies give every engineer and agent the same method on clone and let us adapt it to hardware work; the cost is that upstream changes are pulled by hand, recorded per BKM with the upstream path and commit. Only methods that apply to hardware work are adopted; each candidate is reviewed in its own issue. `.claude/skills/` is the source of truth for skills; `.agents/skills` is a symlink to it so Codex reads the same files.
