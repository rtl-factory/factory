# Adopt upstream agent skills as BKMs, one BKM per topic

We take the method from third-party agent-skill packs (Skills for Real Engineers, tstack, pstack, firstmate; all MIT) and copy it into the repo as BKMs, rather than installing the skills as self-updating plugins or keeping them as chained skills. Committed copies give every engineer and agent the same method on clone and let us adapt it to hardware work; the cost is that upstream changes are pulled by hand, recorded per BKM with the upstream path and commit. The packs overlap heavily, so we write one BKM per topic drawing on every pack that covers it, never one BKM per upstream skill; `wiki/bkm/SOURCES.md` maps sources to BKMs. `.claude/skills/` is the source of truth for skills; `.agents/skills` is a symlink to it so Codex reads the same files.
