# BKMs steer the agents; skills only route

All method lives in BKMs under `wiki/bkm/`. Skills are thin entry points that only route: `bkm-router` lists every BKM and principle and when to follow it, so agents always have that list in context; `flow` points at the flow BKM; `first-mate` and `grill` start a role or session. No skill holds method or chains into another skill, and the repo keeps at most 10 skills. `AGENTS.md` holds only the few rules every session needs and pointers. Captains change how agents work by tuning BKMs. We rejected the upstream style of many small skills invoking each other: it hides the method inside agent plumbing, and every local tweak would fork a skill.
