# Linux-first toolchain: Verilator and cocotb, SymbiYosys, Quartus Prime Lite, in Docker images

The RTL project runs on Linux. RTL is written in the subset of SystemVerilog that both Verilator and Quartus accept. Simulation uses Verilator with testbenches in cocotb (Python); formal verification uses SymbiYosys; FPGA builds use Quartus Prime Lite for the two target boards, the Terasic DE2-115 (Cyclone IV E) and DE10-Lite (MAX 10), programmed over USB-Blaster. Every tool is delivered in pinned Docker images used alike by CI, the self-hosted runner, agents and a devcontainer, so a result on one machine reproduces on another. We chose free tools that run headless in containers over commercial simulators and formal tools, accepting Verilator's partial SystemVerilog testbench support (hence cocotb) and Quartus Lite's device limits. The DV and FV BKMs stay tool-agnostic; this ADR and `tools/toolchain/` name the tools.
