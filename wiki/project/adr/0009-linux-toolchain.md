# Linux-first toolchain: Verilator and cocotb, SymbiYosys, Quartus Prime Lite, installed natively at pinned versions

The RTL project runs on Linux. RTL is written in the subset of SystemVerilog that both Verilator and Quartus accept. Simulation uses Verilator with testbenches in cocotb (Python); formal verification uses SymbiYosys; FPGA builds use Quartus Prime Lite for the two target boards, the Terasic DE2-115 (Cyclone IV E) and DE10-Lite (MAX 10), programmed over their on-board USB-Blaster. Every tool is installed natively on each Linux host at versions pinned in one file and checked by a readiness check, following the method proven in nand2anything. We rejected container images: Altera refuses scripted Quartus downloads and its licence makes republishing an image doubtful, so an image would have to be built from privately stored files anyway, while native installs keep project paths on the Linux filesystem and reach the boards' USB directly. We chose free tools that run headless over commercial simulators and formal tools, accepting Verilator's partial SystemVerilog testbench support (hence cocotb) and Quartus Lite's device limits. The DV and FV BKMs stay tool-agnostic; this ADR and `tools/toolchain/` name the tools.
