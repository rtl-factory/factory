# Blocks

Specs and docs for each project's blocks, mirroring the code: a block's code lives under `src/<project>/<type>/<block>/` (type: `arch`, `rtl`, `dv`, `fv`, `fpga`) and its spec under `wiki/src/<project>/<type>/<block>/`. They change in the same pull request ([flow](../bkm/workflow/flow.md)).
