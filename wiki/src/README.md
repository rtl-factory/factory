# Blocks

Documentation for each hardware block, mirroring the code under `src/<type>/<block>/`. A block's spec lives at `wiki/src/<type>/<block>/` and changes in the same pull request as its code ([flow](../bkm/workflow/flow.md)).

| Type | Holds |
|---|---|
| [arch](arch/README.md) | Architecture models and microarchitecture documents |
| [rtl](rtl/README.md) | Block specs for the hardware implementation |
| [dv](dv/README.md) | Verification plans and testbench docs |
| [fv](fv/README.md) | Formal verification plans and properties |
| [fpga](fpga/README.md) | FPGA implementation: Quartus settings, pins, timing constraints and fit results per board |
