# Performance

Measures and checks Doom on nand2doom's RTL without a board: runs the native performance harness and summarizes its report, attributes a retirement trace to ELF symbols, and reproduces the half-width render oracle from the full-width baseline. Code: `src/nand2doom/scripts/perf/` (`n2d_perf.py`, `n2d_sw_profile.py` and `n2d_render_projection.py`).
