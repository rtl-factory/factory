# nand2doom FPGA

The `fpga` discipline of nand2doom. Code: `src/nand2doom/fpga/`; pins and the Quartus source list in `src/nand2doom/cfg/n2d_quartus.json`; build with `src/nand2doom/scripts/quartus.py`.

- [DE10-Lite board spec](de10_lite/board-spec.md), which also holds the contracts both boards share, because the DE10-Lite is the base board of the config ([why](de10_lite/board-spec.md#why-this-page-holds-the-shared-contracts))
- [DE2-115 board spec](de2_115/board-spec.md)
