# nand2mario scripts

Host-side scripts bound to nand2mario, one folder per script, each with its tests in `tests/`: `board/`, `regression/`, `sw_build/`, `showcase/`. Their PRDs and specs are in the wiki at `wiki/src/nand2mario/scripts/` ([site](https://rtl-factory.github.io/factory/src/nand2mario/scripts/)). `tests/` here holds project-wide checks that belong to no one script.
