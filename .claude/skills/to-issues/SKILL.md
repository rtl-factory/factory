---
name: to-issues
description: Turn an aligned plan, spec or conversation into labelled GitHub issues or an epic. Use when work needs to be split, written up as issues, or when triaging an incoming issue.
---

Follow `wiki/bkm/workflow/issues.md`: split the work into vertical slices that each end in a verifiable state, give each acceptance criteria, "blocked by" links and labels, and make an epic only when the slices cannot reach `main` one by one.
