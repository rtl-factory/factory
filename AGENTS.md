# AGENTS.md

This repo is a hardware development factory: captains (humans) decide, a first mate orchestrates, crewmates (agents) do the work.

- Every change starts with a GitHub issue. Do not change the repo without one.
- Before any work, use the `bkm-router` skill to find the BKMs to follow; for the steps of a change, use the `flow` skill.
- Use the terms in `wiki/project/GLOSSARY.md`.
- Respect the decisions in `wiki/project/adr/`; if your work contradicts one, say so instead of overriding it.
